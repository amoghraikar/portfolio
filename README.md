## ⚡ Overview

An interactive, brutalist dark-mode portfolio built with high-performance Vanilla JavaScript, CSS custom properties, and custom typographic systems (`Eurostile M/N Extended Bold`).

### Key Highlights
- **Interactive Physics Navigation:** Brutalist pills featuring drag-and-drop physics, real-time collision dynamics, and fluid gravity simulations.
- **Procedural Cursor Trails & Particle Dynamics:** Smooth trails, interactive sound synthesis on interactions, and interactive visual feedback.
- **High-Tech Project Viewer:** Full-screen dialog modal with 3D info card inspection, image carousels, and keyboard shortcuts (`I` for Info, `ESC` to close).
- **Multi-Gallery Showcase on Projects:** Interactive tabbed project previews allowing quick browsing across project snapshots.

## 💻 Local Development

To run the portfolio locally without external dependencies:

```bash
# Clone the repository
git clone https://github.com/amoghraikar/portfolio.git
cd portfolio

# Start a local static file server using Python 3
python3 -m http.server 8000
```

Then visit `http://localhost:8000` in your web browser.

Alternatively, using Node.js:
```bash
npx serve .
```
